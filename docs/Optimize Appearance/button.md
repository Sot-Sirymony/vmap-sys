Create a clean, modern **Button Design System** UI showcase in HTML and CSS based on the following specifications:

### 1. Layout & Page Structure

* **Left Sidebar:** Clean white background featuring the `.AW` logo at the top, a `COMPONENTS` eyebrow label, a bold `Buttons.` heading with a blue period, a short description (*"Buttons are used to trigger actions and links. Buttons can contain a combination of text and icon."*), a yellow `WORK IN PROGRESS` pill badge, and a `LINKS` section at the bottom (`Explorations`, `Jira Ticket`).


* **Main Matrix:** Organized into three size sections stacked vertically: **LARGE**, **MEDIUM**, and **SMALL**.


* **Grid Columns & Rows:** Each size section displays 4 columns (**FILLED**, **OUTLINE**, **TEXT**, **LEFT ICON**) across 4 state rows (**NORMAL**, **HOVER**, **PRESSED**, **DISABLED**).



---

### 2. Color Palette

* **Primary (Anywhere Blue):** `#1D90F5`


* **Grey (Grey Light):** `#FA6400` (displayed on a cool slate-grey swatch)


* **Yellow:** `#FCB12A`


* **Green Dark:** `#33B270`



---

### 3. Typography & Shape

* **Font:** Clean geometric sans-serif (`Aa`) with medium-weight, centered `Button` labels.


* **Border Radius:** Full pill shape (`9999px`) on all filled, outline, and icon buttons.
