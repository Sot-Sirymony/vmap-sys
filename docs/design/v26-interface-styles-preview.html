Each column is one style, drawn with the real --style-* tokens. Liquid Glass uses glass only on floating layers: sidebar, header, menus, the dialog, the chart tooltip and the Today hero card. Cards, tables and charts stay solid (D-26-3). With an image backdrop the hero uses the 0.88 / 0.85 floor instead of 0.74 (D-26-5).
